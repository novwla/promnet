# Personal Website - Novela Andauri

Website pribadi sederhana yang dibuat sebagai tugas mata kuliah **Pemrograman Internet**, Program Studi Pendidikan Sistem dan Teknologi Informasi, Universitas Pendidikan Indonesia Kampus Daerah Purwakarta.

## Tentang

Website ini dibuat menggunakan **HTML dasar tanpa CSS**, sesuai dengan ketentuan tugas. Isinya berupa profil singkat, halaman about, project, dan kontak.

## Struktur Halaman

| Halaman | File | Keterangan |
|---|---|---|
| Home | `01-tugas.html` | Halaman utama berisi perkenalan singkat |
| About | `about.html` | Profil lengkap |
| Project | `project.html` | Daftar project yang pernah dikerjakan |
| Contact | `kontak.html` | Informasi kontak |

## Struktur Folder

```
├── 01-tugas.html
├── about.html
├── project.html
├── kontak.html
└── assets/
    └── ovel.jpg
```

## Cara Menjalankan

1. Download atau clone semua file di atas.
2. Pastikan folder `assets` beserta foto profil ikut ter-download.
3. Buka file `01-tugas.html` menggunakan browser (Chrome/Firefox/Edge).

## Yang Dipelajari dari Tugas Ini

- Struktur dasar HTML (`head`, `body`, heading, paragraf)
- Navigasi antar halaman menggunakan tag `<a>`
- Menampilkan gambar dengan tag `<img>`
- Membuat list dengan `<ul>` dan `<li>`
